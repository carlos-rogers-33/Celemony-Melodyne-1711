## 📖 About

Celemony Melodyne is developed by Celemony Software GmbH, a company based in Munich that specializes in pitch and time manipulation technology. The software analyzes monophonic and polyphonic audio, breaks it into individual notes, and lets you move, stretch, correct and reshape those notes directly on a piano roll style interface. Recent builds have refined the note detection engine and improved how edits behave across overlapping audio material, which matters most when working with layered vocals or chord heavy recordings.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer closes without finishing | Restart Windows, then run the setup file again from your Downloads folder. |
| App opens but no audio device listed | Check that your interface is connected and set as default in Windows Sound settings. |
| Plugin not showing in your DAW | Rescan plugin folders inside your DAW, then restart the host application. |
| Playback stutters or drops out | Increase buffer size in the audio settings panel and close background apps. |
| Note detection looks off | Lower the detection sensitivity for the material and reanalyze the region. |
| Unexpected crash on launch | Update your graphics driver and confirm Windows is fully patched. |
